## 📌 Project Description

**Internzo Web** is a responsive and clean landing page template for showcasing internship-related content, branding, or any tech startup idea. It features:

- 🧭 A responsive navbar
- 🖼️ Hero section
- 📄 About and service sections
- 📱 Mobile responsive design
- 🎨 Stylish transitions and clean UI
